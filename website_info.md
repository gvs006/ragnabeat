# Bem-vindo ao Ragnabeat!

## Informações Gerais
* **Episódio:** Encontro com o Desconhecido (Pré-Renovação)
* **Nível Máximo:** 99 (Base) / 70 (Classe)
* **Atributos Máximos:** 99
* **ASPD Máxima:** 190

## Taxas do Servidor (Rates)
* **Experiência Base:** 500x
* **Experiência de Classe:** 500x
* **Drop Geral:** 20x
* **Drop Geral de MVP:** 10x

## Comandos Liberados para Jogadores
| Comando | Descrição |
| --- | --- |
| `@commands` | Exibe a lista completa de comandos disponíveis. |
| `@time` | Exibe a data e horário atual do servidor. |
| `@go` | Teleporta o personagem para uma cidade. |
| `@die` | Faz o personagem morrer instantaneamente. |
| `@refresh` | Atualiza o visual do personagem e corrige possíveis bugs gráficos. |
| `@rates` | Mostra as taxas de EXP e Drop atuais do servidor. |
| `@exp` | Exibe as taxas de experiência do personagem. |
| `@ii / @iteminfo` | Exibe informações detalhadas sobre um item. |
| `@mi / @mobinfo` | Exibe informações detalhadas sobre um monstro. |
| `@party` | Permite criar um grupo. |
| `@partyoption` | Permite alterar as configurações do grupo. |
| `@changeleader` | Transfere a liderança da party para outro membro do grupo. |
| `@noask` | Bloqueia convites automáticos, como pedidos de party, guild ou trade. |
| `@noks` | Ativa ou desativa a proteção contra Kill Steal (KS). |
| `@mail` | Abre o sistema de correio do jogo (RodEx). |
| `@at / @autotrade` | Mantém sua loja aberta mesmo offline. |
| `@feelreset` | Redefine todos os mapas de afinidade Solar, Lunar e Estelar. |
| `@hatereset` | Remove todos os monstros de oposição Solar, Lunar e Estelar. |
